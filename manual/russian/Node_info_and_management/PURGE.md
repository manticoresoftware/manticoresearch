# PURGE

`PURGE` удаляет выбранные данные, связанные с таблицей. Цель очистки определяет, что именно будет удалено.

```sql
PURGE <target> FROM TABLE <table_name>;
```

Единственная поддерживаемая сейчас цель — `INDEXER_RT_BULK`.

## PURGE INDEXER_RT_BULK

```sql
PURGE INDEXER_RT_BULK FROM TABLE products;
```

`PURGE INDEXER_RT_BULK` удаляет весь корневой каталог промежуточного хранения, используемый [пакетной вставкой с помощью indexer](../Data_creation_and_modification/Adding_documents_to_a_table/Adding_documents_to_a_real-time_table.md#Indexer-assisted-bulk-insertion), включая каталоги и файлы, оставшиеся после прерванной загрузки. Запускайте ее только после того, как убедитесь, что для таблицы не выполняется вспомогательная загрузка.

Оператор требует существующую локальную real-time-таблицу, которая не входит в кластер репликации. Он удаляет только состояние промежуточного хранения для вспомогательной загрузки и не изменяет схему таблицы или проиндексированные документы. Если корневой каталог промежуточного хранения отсутствует, оператор завершается успешно, не внося изменений. В режиме без конфигурации `DROP TABLE` также удаляет корневой каталог вспомогательного промежуточного хранения таблицы.
