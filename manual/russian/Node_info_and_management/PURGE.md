# PURGE

`PURGE` удаляет выбранные данные, связанные с таблицей. Цель очистки указывает, что именно будет удалено.

```sql
PURGE <target> FROM TABLE <table_name>;
```

Сейчас поддерживается только цель `BULK_IMPORT`.

## PURGE BULK_IMPORT

```sql
PURGE BULK_IMPORT FROM TABLE products;
```

`PURGE BULK_IMPORT` удаляет весь промежуточный корневой каталог, используемый [массовым импортом](../Data_creation_and_modification/Adding_documents_to_a_table/Adding_documents_to_a_real-time_table.md#Bulk-import), включая каталоги и файлы, оставшиеся после прерванной загрузки. Выполняйте эту команду только после того, как убедитесь, что для таблицы не выполняется загрузка напрямую на диск.

Команда требует существующую локальную таблицу реального времени, которая не входит в кластер репликации. Она удаляет только промежуточное состояние для загрузки напрямую на диск и не изменяет схему таблицы или проиндексированные документы. Если промежуточный корневой каталог отсутствует, команда завершается успешно без каких-либо изменений. В режиме без конфигурационного файла `DROP TABLE` также удаляет промежуточный корневой каталог таблицы для загрузки напрямую на диск.
